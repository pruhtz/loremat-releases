# Loremat – Releases

Download and update feed for [Loremat](https://github.com/pruhtz/loremat),
a macOS menu bar app that inserts context-aware placeholder text.

- **Latest release:** see [Releases](https://github.com/pruhtz/loremat-releases/releases/latest)
- **Update feed:** [`appcast.json`](appcast.json) – read by the app's built-in
  updater (one public GET, no identifiers sent)

## Installing

1. Download `Loremat-<version>.dmg` from the latest release and drag the app to *Applications*.
2. First launch: the app is not notarised – right-click → *Open*, then grant the
   Accessibility permission in *System Settings → Privacy & Security → Accessibility*.
